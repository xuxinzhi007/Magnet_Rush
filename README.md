# 磁暴工坊 · Magnet Rush

## 世界与目标

近未来的“磁暴回收队”正在失控的轨道工厂中抢救反应堆。你是唯一能操控实验性磁暴核心的场控工程师。每一波敌对清理无人机会逼近核心；你必须用磁力碎片把它们击毁，清空波次，活得越久、连锁越高，回收的能量越多。

这不是单纯打怪：你的目标是完成越来越危险的清场任务，并刷新最高连锁记录。

- `WASD` / 方向键：移动
- `Q` / `E`：切换青色 / 橙色极性
- 按住鼠标左键：锁定并拉回附近同极性碎片
- 松开鼠标左键：朝鼠标方向把碎片甩出
- `Space`：过载脉冲，推开周围所有碎片
- `R`：失败后重开
- `B`：消耗 5 废料，在当前位置部署磁力塔
- `F5`：保存当前运营状态
- `F9`：加载已保存状态

## 一局怎么玩

1. 移动核心，按 `Q/E` 选择当前极性。
2. 靠近同色碎片，按住鼠标左键把它锁定并拉回。
3. 拖动鼠标瞄准敌人，松开左键把碎片甩出去。
4. 连续击破保持连锁；能量满时按 `Space` 释放过载脉冲救场。
5. 清空当前波次进入下一波；敌人碰到核心则任务失败。

靠近黄色资源节点会自动回收废料。磁力塔会在附近自动锁定并清除敌人，这是“自由部署网络”的第一步。

## 打包

在 PowerShell 中运行 `./build.ps1 -Target all`，会生成 `dist/magnet-rush.exe` 和 `dist/` 下的 WASM 网页版本。游戏每 60 帧自动保存一次，保存文件为 `magnet_rush_save.json`。

方向锁定：新增内容必须强化“移动、极性、锁定、拉回、甩击、连锁、过载风险”，不得漂移为普通摆放或挂机数值游戏。
